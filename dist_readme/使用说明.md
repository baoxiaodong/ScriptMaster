## 产品简介

**ScriptMaster** 是一款专为短视频创作者、影视制作团队打造的AI分镜生成工具。通过先进的大语言模型技术，能够自动将小说文本智能拆解为专业的分镜脚本，大幅提升创作效率。

### 核心优势

✅ **高效批量处理**：支持20-100集并行生成，3线程并发处理  
✅ **多模型支持**：兼容OpenAI、Claude、Gemini、通义千问等6大主流AI模型  
✅ **流式实时输出**：边生成边显示，无需等待完成  
✅ **智能重试机制**：自动检测失败集数，支持一键补全  
✅ **灵活导出格式**：支持Word文档、CSV表格、Excel多工作表导出

### 适用场景

- 🎬 短视频剧本创作（抖音、快手、B站）
- 📺 网络剧/微短剧分镜设计
- 📖 小说IP改编前期策划
- 🎥 影视项目预可视化

## 快速开始

### 第一步：启动程序

双击 `.exe` 文件，等待程序加载（首次启动约需5-10秒）。

### 第二步：配置API密钥

在左侧边栏完成以下设置：

1. **选择模型服务商**
    - OpenAI (GPT-4o/GPT-4-turbo)
    - Anthropic (Claude-3.5-sonnet/Claude-3-opus)
    - Google Gemini (Gemini-2.0-flash/Gemini-1.5-pro)
    - 阿里云通义千问 (qwen-plus/qwen-turbo)
    - OpenRouter（多模型聚合平台）
    - 自定义API（兼容OpenAI格式的第三方服务）
2. **输入API Key**
    - 从对应平台获取API密钥
    - 粘贴到"API Key"输入框
3. **选择模型**
    - 根据需求选择合适的模型版本
4. **验证连接**
    - 点击「🔑 验证 API Key」按钮
    - 看到 "✅ API 连接成功" 提示后即可开始使用

> 💡 **提示**：API Key仅存储在本地浏览器会话中，关闭程序后自动清除，不会上传到任何服务器。

### 第三步：上传小说文件

#### 文件格式要求

支持两种格式：

- **Excel文件**（.xlsx / .xls）- 推荐
- **CSV文件**（UTF-8编码）

#### 数据格式规范

| 列号  | 内容           | 说明                      |
| ----- | -------------- | ------------------------- |
| 第1列 | 章节标题、英文 | 如："第一章 重生归来"英文 |
| 第2列 | 章节正文、英文 | 完整的小说内容英文        |

#### 示例表格

| 章节标题     | 章节正文                     |
|----------|--------------------------|
| 第一章 冰封前夕 | 2099年的冬天来得格外早...（完整正文）   |
| 第二章 安全屋  | 林峰站在落地窗前，看着窗外飘雪...（完整正文） |

> ⚠️ **注意事项**：
> - CSV文件必须使用 **UTF-8编码** 保存
> - 不要包含表头行（程序会自动识别）
> - 单章正文建议控制在5万字以内

### 第四步：生成分镜脚本

#### 模式一：小说Excel模式（推荐新手）

1. **选择章节**
    - 上传文件后，系统会显示章节列表
    - 勾选需要处理的章节（可多选）

2. **配置生成参数**
    - **总集数**：设置要生成的分镜集数（默认20集，范围10-100集）
    - 系统会自动按每3集一批进行并行处理

3. **开始生成**
    - 点击「🚀 开始生成 XX 集分镜」按钮
    - 观察进度条和实时日志
    - 预计耗时：20集约3-5分钟，100集约15-20分钟

4. **查看结果**
    - 生成完成后，自动显示所有集数的分镜表格
    - 每集包含：镜号、场景、画面内容、台词、音效

5. **补全失败集数**
    - 如有集数生成失败或镜头数不足，点击「🔄 补全缺失集数」
    - 系统会重新调用AI生成失败的集数

#### 模式二：剧本全流程模式（适合专业用户）

提供更精细的控制：

- 先生成三幕式创意大纲
- 再逐集生成分集大纲
- 最后生成详细分镜脚本

## 功能详解

### 输出格式说明

生成的分镜脚本包含以下字段：

| 字段                | 语言 | 说明                     |
|-------------------|----|------------------------|
| **镜号**            | 数字 | 镜头序号（1, 2, 3...）       |
| **场景**            | 中文 | 拍摄地点（如：宴会厅、街道、卧室）      |
| **画面内容 (Visual)** | 中文 | 详细的视觉描述，包括人物动作、表情、镜头运动 |
| **台词 (Dialogue)** | 英文 | 角色对白（便于国际化制作）          |
| **音效 (SFX)**      | 英文 | 背景音乐、环境音、特效音           |

### 示例输出

**镜号**: 1 场景: 宴会厅 画面内容: 贝拉站在聚光灯下，高举酒杯，眼神轻蔑地扫视全场。 台词: Narrator: In this era, vision
determines class. 音效: Elegant background music, clinking glasses
**镜号**: 2 场景: 宴会厅 画面内容: 突然，所有高清屏幕同时闪烁雪花，全场陷入混乱。 台词: Bella: What's happening? 音效:
System crash electronic sound effect, crowd gasping

### 导出功能

生成完成后，可选择以下导出方式：

1. **导出为Word文档**
    - 点击「📄 导出为 Word」
    - 每个集数单独一页，格式美观
    - 适合打印和审阅

2. **导出为CSV表格**
    - 点击「📊 导出当前集为 CSV」
    - 标准CSV格式，可用Excel打开
    - 适合数据分析和二次编辑

3. **导出为Excel多工作表**
    - 点击「📑 导出全部为 Excel」
    - 每个集数一个Sheet，便于管理
    - 适合团队协作

### 高级功能

#### 断点续传

如果生成过程中断（网络故障、程序崩溃）：

1. 重新打开程序
2. 上传相同文件
3. 点击「🔄 补全缺失集数」
4. 系统会自动跳过已成功的集数

#### 批量处理优化

- **并行策略**：每3集为一组，同时调用3个AI线程
- **智能错峰**：线程间间隔0.5秒启动，避免API限流
- **自动重试**：每批次最多重试2次，提高成功率

#### 自定义API地址

如果使用私有部署的模型或国内镜像：

1. 选择"自定义API"或对应服务商
2. 在"API Base URL"中输入自定义地址
3. 例如：`https://api.your-domain.com/v1`

## 常见问题

### ❓ API相关问题

#### Q1: API Key验证失败怎么办？

**可能原因及解决方案：**

1. **Key复制错误**
    - 检查是否有前后空格
    - 确认没有遗漏字符

2. **Key未开通服务**
    - 登录对应平台确认已激活该模型
    - 检查账户是否完成实名认证

3. **余额不足**
    - 查看账户余额/额度
    - 充值后重试

4. **区域限制**
    - 部分模型需要科学上网
    - 尝试更换为国内模型（如通义千问）

#### Q2: 生成时提示"请求过于频繁"？

**解决方案：**

- 等待30-60秒后重试
- 减少单次生成的集数（如从50集改为20集）
- 升级API套餐以获得更高配额


### ❓ 文件相关问题

#### Q3: 上传CSV后显示乱码？

**解决方案：**

1. 用记事本打开CSV文件
2. 点击"文件" → "另存为"
3. 编码选择 **UTF-8**
4. 重新上传

#### Q4: 提示"未检测到有效数据"？

**检查清单：**

- ✅ 确认文件至少有2列数据
- ✅ 确认第2列（正文）不为空
- ✅ 移除可能的表头行
- ✅ 检查是否有全空行

#### Q5: 支持多大的文件？

**建议限制：**

- 单次上传不超过50章
- 总字数控制在50万字以内
- 超大文件建议分批处理

---

### ❓ 生成质量问题

#### Q6: 生成的分镜不够详细？

**优化方法：**

1. 更换更强大的模型（如GPT-4o）
2. 在小说正文中增加更多细节描写
3. 调整Prompt模板（联系技术支持获取高级版）

#### Q7: 某些集数生成失败？

**处理步骤：**

1. 查看错误提示（如"超时"、"额度不足"）
2. 点击「🔄 补全缺失集数」重试
3. 如仍失败，手动减少该章节字数
4. 联系技术支持获取帮助

#### Q8: 镜头数量不足20个？

**说明：**

- 系统会自动检测每集镜头数
- 少于20个镜头会被标记为"需要补全"
- 点击补全按钮重新生成即可

---

### ❓ 性能相关问题

#### Q9: 生成速度很慢？

**影响因素：**

- 网络延迟（访问国外API较慢）
- 模型响应时间（复杂任务耗时更长）
- API服务商负载

**加速建议：**

- 使用国内模型（通义千问）
- 避开高峰时段（晚上8-10点）
- 升级到更快的API套餐

#### Q10: 程序卡死无响应？

**解决方法：**

1. 点击页面底部的「🔄 强制重置系统状态」按钮
2. 如无效，关闭程序重新启动
3. 清理浏览器缓存（Streamlit基于浏览器）

### 🎯 提高工作效率

1. **分批处理**
    - 先处理10集测试效果
    - 满意后再批量生成剩余集数

2. **建立模板库**
    - 保存常用的场景描述
    - 复用成功的分镜结构

3. **团队协作**
    - 导出Excel后分配给不同成员审核
    - 使用批注功能记录修改意见
